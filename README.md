# Eke

A theme and icon pack for VS Code and JetBrains IDEs.

## Features

- Custom color theme for VS Code and JetBrains IDEs
- Icon pack to complement the theme

## Installation

### VS Code

1. Open the **Extensions** panel (`Ctrl+Shift+X` / `Cmd+Shift+X`)
2. Search for **Eke**
3. Click **Install**

### JetBrains

1. Go to **Settings → Plugins → Marketplace**
2. Search for **Eke**
3. Click **Install** and restart your IDE
